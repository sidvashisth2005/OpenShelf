## OpenShelf 0.4.0: folders, messages and joining a team

- **Share whole folders:** pick several files at once or a whole folder (like a project with 10 code files). Each
  file gets a preview, and **Download all** gives everything as one .zip. Code and text files are now supported.
- **Messages:** members can message the admin privately, and admins can reply and send announcements to
  everyone. New messages show an unread badge.
- **Join a team's server:** if you installed OpenShelf but want to use someone else's server, paste their invite
  link on the first screen. OpenShelf then opens their server.
- **Easier to find shared posts:** after joining, members land on the **Feed**, which shows everything shared on
  the server, including the admin's posts. The admin's profile page now works too.
- The Terms and Privacy Policy now mention messages.
